# DCM 연동 현황 대시보드 - 업체 배포용 공용양식 v9

대웅 내부 기본 거래처 데이터를 포함하지 않는 GitHub Pages용 공용양식입니다.
각 업체에 대시보드 URL과 해당 업체의 Excel 파일을 전달하면, 업체가 브라우저에서 직접 Excel을 업로드하여 본인 현황을 확인할 수 있습니다.

## 사용 방법
1. GitHub Pages 주소에 접속합니다.
2. `월별 Excel 업데이트`에서 전달받은 Excel 파일을 선택합니다.
3. 파일 내 `6월`, `7월`, `8월` 등 월 시트를 자동으로 인식합니다.
4. 월/업체를 선택하여 연동률, 연동 필요처, 공급 절대처수, 전월 변동을 확인합니다.
5. 같은 월·업체의 파일을 다시 업로드하면 해당 월 데이터가 새 파일 기준으로 교체됩니다.

## 계산 기준
- 전체 연동률 = O / (O + X)
- 평가처수 = 대웅제약/대웅바이오/한올바이오의 O/X를 법인별 각각 평가
- 연동 필요 절대처수 = 업체/권역 내부에서 실사업자번호 기준 중복 제거
- 공급 절대처수 = 업체/권역 내부에서 3개 법인 중 하나라도 O/X가 있으면 실사업자번호 기준 1처
- 신규 공급 = 전월 전체 미공급 -> 당월 하나라도 O/X
- 공급 중단 = 전월 하나라도 O/X -> 당월 전체 미공급
- 신규 공급처수 - 공급 중단처수 = 공급 절대처수 증감
- 동일 실사업자번호가 서로 다른 도매업체에 존재하는 경우에는 각 업체에서 각각 1처로 계산
- 공급 중단 상세에는 중단 직전 법인별 O/X 상태 표시

## 개인정보/데이터 처리
- 기본 거래처 데이터는 ZIP에 포함되어 있지 않습니다.
- Excel 파일은 브라우저에서 직접 읽습니다.
- 업로드한 데이터는 해당 브라우저 localStorage에 저장됩니다.
- 서버 업로드 기능은 없습니다.
- 공용 PC에서는 사용 후 `업로드 데이터 초기화`를 권장합니다.

## GitHub Pages
압축을 푼 파일 전체를 저장소 루트에 올리고 Settings > Pages에서 `Deploy from a branch`, `main`, `/(root)`를 선택합니다.

## 2026-10-08 이중 작성 Action Board
- 마스터 Action을 파란색 **읽기 전용**으로 표시하며, 업체 조치 내용은 초록색 **입력** 칸에 별도 작성합니다.
- 입력 시 `partnerSaveAction`으로 Google Apps Script를 호출하여 Google Sheet **Action Board N:T**에 저장합니다. 마스터의 A:M은 수정하지 않습니다.
- 저장 실패 시 해당 브라우저에 미전송 값을 보관하고 재전송하며, Excel 다운로드에는 양측 입력 항목이 모두 들어갑니다.
- 실제 서버 동기화는 마스터 저장소의 `apps-script/Code.gs`가 운영 Google Apps Script에 새 버전으로 배포되어야 가능합니다.

- 처음에는 Action 30건, Risk 60건만 그려 초기 DOM 부담을 줄였습니다. 더 보기로 추가 표시합니다.

- 이 기능은 최신 `Code.gs`를 운영 Apps Script 배포에 반영해야 정상 동작합니다. 서버 URL이 404이면 GitHub Pages만 업데이트해도 해결되지 않습니다.
